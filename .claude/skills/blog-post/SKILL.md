# Статті блогу SINSERITA

Блог не має адмінки чи бази даних. Кожна стаття — це Markdown-файл у репозиторії,
а сайт збирається з цих файлів під час деплою на Vercel.

## Де що лежить

- Стаття: `content/blog/<slug>.md`. Назва файлу = адреса сторінки: `/blog/<slug>`.
- Картинки статті: `public/blog/<slug>/…` → у тексті посилання `/blog/<slug>/файл.jpg`.
- Код, що читає статті: `lib/blog.ts`. Сторінки: `app/blog/page.tsx`, `app/blog/[slug]/page.tsx`.

## Slug (назва файлу)

Лише латиниця в нижньому регістрі, цифри й дефіси: `yak-obraty-pryazhu-dlia-svetra.md`.
Транслітеруй українську за офіційною таблицею (ж→zh, х→kh, ц→ts, ч→ch, ш→sh, щ→shch,
ю→iu, я→ia, є→ie, ї→i, й→i, ь та апостроф → пропустити). 3–6 слів, без стоп-слів, якщо можна.
Не змінюй slug уже опублікованої статті — зламаються посилання.

## Шаблон файлу

```markdown
---
title: "Як обрати пряжу для светра"
date: 2026-10-01
excerpt: "Коротко про склад, метраж і щільність — що перевірити перед покупкою."
cover: /blog/yak-obraty-pryazhu-dlia-svetra/cover.jpg
tags: ["поради", "меринос"]
draft: false
---

Вступний абзац…

## Підзаголовок

Текст…
```

Поля:

| Поле      | Обов'язкове | Що це |
|-----------|-------------|-------|
| `title`   | так | Заголовок (він же H1 сторінки) |
| `date`    | так | Дата публікації `YYYY-MM-DD` |
| `excerpt` | бажано | 1–2 речення: анонс у списку та опис для Google/соцмереж |
| `cover`   | бажано | Обкладинка 16:9 (напр. 1600×900) — шлях `/blog/<slug>/…` або https-URL |
| `tags`    | ні | Список рядків |
| `draft`   | ні | `true` — стаття прихована на робочому сайті (видно лише в preview та локально) |

## Текст

- Мова — українська. Бренд пишеться `SINSERITA`.
- У тексті не використовуй `#` (H1) — заголовок береться з `title`. Структура: `##`, `###`.
- Підтримується GitHub Markdown: списки, таблиці, цитати, посилання, картинки `![опис](/blog/<slug>/foto.jpg)`.
  Сирий HTML не рендериться — не використовуй його.
- Посилання на товар: `/product/<артикул>`, на інші статті: `/blog/<slug>`.
- Кожна картинка має змістовний alt-текст. Стискай фото (JPG/WebP, до ~300 КБ).

## Перевірка перед публікацією

```bash
pnpm install   # якщо залежності ще не встановлені
pnpm build
```

Збірка падає з назвою файлу, якщо slug, `title`, `date` чи `tags` некоректні — виправ і повтори.
Переконайся, що стаття є в списку маршрутів `/blog/[slug]` у виводі збірки.

## Публікація

1. Працюй у гілці, закоміть статтю (і картинки) з повідомленням на кшталт `Blog: <назва статті>`.
2. Запуш гілку. Vercel збере preview-деплой — там видно навіть чернетки, можна показати власнику.
3. Злиття в `main` = публікація: Vercel автоматично оновлює робочий сайт.

Пуш напряму в `main` — лише якщо власник явно про це попросив.
Щоб зняти статтю з сайту, не видаляючи її, постав `draft: true`.
